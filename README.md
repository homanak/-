# P-0218 — South Facade Design

Architectural design and presentation package for the **South Elevation** of project **P-0218**.

## Project contents

| File | Description |
|---|---|
| `Faced.png` | Daylight perspective render; visual reference for the facade |
| `My_PDF.pdf` | Seven-page architectural drawing set, including the south elevation and technical elevations |
| `01 -temp.dwg` | CAD source drawing |
| `facade-prompts-p0218-fa.md` | Persian booklet brief and 14 standalone, copy-ready image-generation prompts |
| `Facade_Prompts_P0218_FA.txt` | Plain-text version of the prompt set for easy copying |

## Booklet sequence

The 14-sheet editorial sequence moves from project identity and design narrative to the daylight hero image, full elevation, three consecutive enlarged elevation zones, a night study, material and detail studies, facade axonometry, urban-context sketch, execution coordination, and a closing image.

The visual identity uses warm ivory, charcoal, warm gray, glass blue-gray, and a restrained champagne-gold narrative line. The supplied render and drawings remain the source of truth for facade geometry.

## Technical and attribution note

The prompt set is a graphic-production brief, not a substitute for CAD drafting or construction documentation. Dimensions and technical linework must be checked against the supplied CAD/PDF. Image-generation tools may not reliably reproduce Persian typography or precise technical drawings; final text and drawings should be typeset and verified in appropriate software.

The supplied drawing PDF may contain project-party contact details. This repository is public by request; review source documents for information you intend to publish before sharing the repository link.
